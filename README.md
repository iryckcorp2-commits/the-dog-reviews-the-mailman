The Dog Reviews the Mailman: a dog reviews the mailman:

> One star. He delivers the mail but never stays to play, and his uniform smells like other dogs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 95 characters) to the output directory. It uses only the Python 3 standard library, needs no network, and two runs produce byte-identical files. It refuses to write an entry that is blank, multi-line, or over 199 characters.
